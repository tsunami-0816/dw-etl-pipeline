# 后端开发实现文档 · dw-etl-pipeline

> 第 5A 步持续回写。接口形态为非 HTTP：存储过程 + CLI + 数据表/报告；不提供服务端口、登录/token 或 OpenAPI，HTTP 健康检查与 6.5 契约校验不适用。

## 1. 模块与依赖

| 模块 | 实现范围 | 公共组件 |
|---|---|---|
| M1 | `sql/init/`、`gen_data.py`：四层模型、SCD2、90 天固定种子与 3% 脏订单 | `dw_common.connect` |
| M2 | 5 个存储过程：事务、运行日志、清洗游标、P0、幂等/锁/失败层重跑 | `etl_run_log` |
| M3 | Spark/pandas 重算、stg+upsert、全外连接对账 | `stg_dws_daily_channel_spark` |
| M4 | 12 指标、字段血缘、DQ01～DQ05 双实现与治理表/报告 | `dq_rules.yml` |
| M5 | Q1/Q2/Q3 前后 SQL、5 次 `EXPLAIN ANALYZE` 中位数与 slow log | `perf_benchmark.py` |
| M6 | 日调度、补数、部署、运维、pytest 与证据集 | 退出码与 `run_summary.json` |

核心版本：PyMySQL 1.1.1、SQLAlchemy 2.0.36、pandas 2.2.3、PyYAML 6.0.2、python-dotenv 1.0.1、pytest 8.3.3；Spark 可选 3.5.3。版本在根目录 `requirements*.txt` 锁定。

## 2. 非 HTTP 接口契约

### 存储过程

| 过程 | 入参 | 出参/返回 | 异常 |
|---|---|---|---|
| `sp_etl_daily` | `p_date DATE`，会话变量出参 | `p_status=success/skipped/blocked/failed`、`p_rows` | SQL 异常 failed；DQ P0 blocked |
| `sp_load_ods` | `p_date,p_batch_id`，`OUT p_rows` | 当日 ODS 总行数 | 回滚并记 failed |
| `sp_build_dwd` | 同上 | 清洗明细、SCD2、`dq_issue` | 空渠道/重复率 >5% SIGNAL 45000 |
| `sp_build_dws` | 同上 | 日渠道/日品类聚合行数 | 回滚并记 failed |
| `sp_build_ads` | 同上 | 4 张 ADS 行数 | 回滚并记 failed |

## 5. 关键结论与已知限制

1. **口径一致性已机器校验**：`spark/reconcile.py::aggregate_channel`（pandas 实现）与 `sp_build_dws` 同口径，14 天 + 90 天逐日 full outer join 对账 diff=0；Spark 聚合 `_aggregate_spark` 用 Spark 函数重写同一口径，但因环境未端到端执行。
2. **P0 阻断证据不随回滚丢失**：D-36 实测 DWD 回滚（DWD/ADS 当日 0 行），但 `dq_report`（DQ01 P0 blocked）与 `dq_alert`（P0 open）已先提交落盘——治理证据先于下游写入提交。
3. **源修复后的重抽约束**：幂等预检会跳过已 success 的 ODS 层；源数据修复后必须重抽该日 ODS（清空 ODS + 日志），DWD 才会读到修复后的源。已在 ops.md/实现文档记录为运维注意点。
4. **Spark 环境限制（已知）**：本项目目录 `工作流测试` 含中文，Windows 下 pyspark 3.5.3 启动 JVM 时 `ClassNotFoundException: org.apache.spark.deploy.SparkSubmit`（类路径编码问题），非代码缺陷。在 ASCII 路径或配置正确 winutils/SPARK_HOME 的环境即可运行；降级 pandas 已验证 0 差异。
5. **并发锁互斥（D-24）未实测**：`GET_LOCK` 代码已实现（超时 0、异常 handler 释放），留第 6/8 步并发起两个 run_daily 补互斥证据。

## 6. 安全与 Mock

口令只从环境变量或本地 `.env` 读取，示例仅占位符；初始化 SQL 的密码占位符由 `run_sql.py` 校验并渲染。业务值全部参数化，SQL 文件名/表名使用代码内白名单。无第三方外部服务，无 Mock 外部依赖。5A 收尾将运行工作流 secrets/SAST 快扫并记录真实结果。
