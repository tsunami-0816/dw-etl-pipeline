## 三、四象限说明（适配非 HTTP）

提示词要求「每个核心接口正向/反向/边界/越权」。本项目无 HTTP 接口与权限体系，四象限映射为：

- **正向**：`sp_etl_daily` 正常出数（L2-1）、`run_daily` 全链路 exit 0（L4）
- **反向（异常治理）**：注入 100% 空渠道 → P0 blocked + DWD 回滚（L2-3）；5 类脏数据拦截（L1 + L2）
- **边界**：日期范围校验（`validate_date_range` 90 天上限、倒序拒绝）、脏数据率边界（0% / 非法 1.1）、金额对账容差 0.01（L1）
- **幂等（替代越权，本项目无多租户）**：同日连跑两次结果一致（L2-2）、回补 skipped 不翻倍（第 7 步 L-05）

## 四、用例独立性与数据隔离

- L1 不碰 DB，无状态，任意顺序可跑。
- L2/L4 正向/幂等在干净基线日 `2026-11-28` 上跑：`sp_etl_daily` 幂等（已跑过返回 skipped，不改变结果），不污染 11-10~11-28 基线。
- L2 P0 阻断用例在**隔离日 `2026-11-29`** 操作：fixture `isolated_day` 造单日增量 → 初始化 → 注入 → 断言 → teardown 清理（`DELETE` 各层/日志/治理表 dt=11-29），全程不碰基线窗口。
- L3 锁互斥仅用 `GET_LOCK`，不碰业务表。
